# 키트 목록 자동화 (vocab.json) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 스토리보드 `Objects:` 제약을 키트 폴더별 `vocab.json`에서 조립하고 storyboard.json `kit`으로 고르게 해, 새 키트 추가 시 스토리보드 코드를 고치지 않게 한다.

**Architecture:** 각 키트 폴더(`kit/modules/<kit>/`)에 `index.ts`(`*_ELEMENTS`)와 `vocab.json`. `scripts/lib/kit-vocab.mjs`는 플러그인 `kit/modules/*/vocab.json`을 읽어 문장을 조립(objects 합집합, avoid 교집합). `storyboard.mjs`는 `sb.kit`(기본 logistics)을 검증해 넘긴다.

**Tech Stack:** Node 22 ESM (scripts), TypeScript 5.9 (kit), vitest 5 (`import.meta.glob` 사용 가능).

**Spec:** `docs/superpowers/specs/2026-10-15-kit-vocab-design.md`

## Global Constraints

- `vocabSentence(['logistics'])` = `Only depict objects from this list: a warehouse with loading docks, box trucks and vans, yellow forklifts, pallets with cardboard boxes or blue crates, shipping containers, roads with a dashed center line, paved lots, round lollipop trees and cone trees, blue map pins, simple office buildings. Do not include: cars, people, text, logos, distant towns, water, bridges.` (현재와 완전히 동일)
- 키트 이름 = 폴더 이름. vocab.json이 있는 폴더만 키트.
- storyboard.json `kit` 기본 `"logistics"`. 오류 경로 `storyboard.kit`.
- `CAMERA_ISO` 문장 불변.
- 플러그인 버전 0.2.2.
- git commit은 단독 Bash 호출(같은 줄에 `-n` 들어간 명령 금지: 훅 오탐). 파일 수정은 Edit/Write.

## Review Focus

1. 여러 키트 선택 시 한 키트가 허용하는 것(concept의 text)이 금지 목록에 남지 않음 → 교집합 (Task 2 테스트).
2. avoid 교집합이 비면 `Do not include` 구절 자체가 빠짐(빈 콜론 문장 없음) (Task 1 테스트).
3. 같은 구문이 두 키트에 있으면 한 번만 (Task 1 테스트).
4. vocab.json 형식 오류(objects 비어 있음, avoid가 문자열) → 어느 파일인지 담은 오류 (Task 1 테스트).
5. `kit: []`, `kit: 3`, `kit: ['logistics', 'nope']` → `storyboard.kit` 오류에 사용 가능한 키트 목록 (Task 2 테스트).

```js
import { existsSync, readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';

/** 스토리보드 프롬프트 제약. 키트별 문구는 kit/modules/<kit>/vocab.json (키트 추가 시 이 파일은 고치지 않는다) */
export const KIT_ROOT = fileURLToPath(new URL('../../kit/modules/', import.meta.url));
/** scene의 아이소 방향 target + [45, 67, 78]: 방위 30°, 고도 약 37° */
export const CAMERA_ISO = 'Orthographic isometric view (no perspective distortion), looking from the front-right about 30° off the front face, elevated about 37°.';

const isStr = (v) => typeof v === 'string' && v.length > 0;

export function loadKits(root = KIT_ROOT) {
  const kits = new Map();
  for (const name of readdirSync(root).sort()) {
    const file = join(root, name, 'vocab.json');
    if (!existsSync(file)) continue;
    const where = `${name}/vocab.json`;
    let v;
    try {
      v = JSON.parse(readFileSync(file, 'utf8'));
    } catch (e) {
      throw new Error(`${where}: JSON 형식 오류 (${e.message})`);
    }
    if (!isStr(v?.label)) throw new Error(`${where}: label은 비어 있지 않은 문자열`);
    if (typeof v.objects !== 'object' || v.objects === null || Array.isArray(v.objects) || !Object.keys(v.objects).length || !Object.values(v.objects).every(isStr)) {
      throw new Error(`${where}: objects는 { type: 구문 } 1개 이상`);
    }
    if (!Array.isArray(v.avoid) || !v.avoid.every(isStr)) throw new Error(`${where}: avoid는 문자열 배열`);
    kits.set(name, { label: v.label, objects: v.objects, avoid: v.avoid });
  }
  return kits;
}

const pick = (kits, root) => {
  const all = loadKits(root);
  return kits.map((k) => {
    const v = all.get(k);
    if (!v) throw new Error(`알 수 없는 키트 '${k}'. 사용 가능: ${[...all.keys()].join(', ')}`);
    return v;
  });
};

export function vocabSentence(kits = ['logistics'], root = KIT_ROOT) {
  const sel = pick(kits, root);
  const objects = [...new Set(sel.flatMap((v) => Object.values(v.objects)))];
  const avoid = sel[0].avoid.filter((a) => sel.every((v) => v.avoid.includes(a)));
  return `Only depict objects from this list: ${objects.join(', ')}.${avoid.length ? ` Do not include: ${avoid.join(', ')}.` : ''}`;
}

export function kitTypes(kits, root = KIT_ROOT) {
  return [...new Set(pick(kits, root).flatMap((v) => Object.keys(v.objects)))];
}
```
